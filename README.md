# Frontend2
# What is this project?
A project displaying a simplified landing page for an automotive database called Kinnetica Automotive. This project was developed in 10 weeks from my front-end class.

# Primary Goal of the project
My goal in this project was to utilize a simplified JavaScript library button and other clickable interactions to guide the user simply through the page. I additionally wanted to focus my aesthetic usability principle and hierarchy to display clear messaging.
